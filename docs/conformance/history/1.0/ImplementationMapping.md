## Concrete state and abstraction relation

The modeled context is one user performing a sequential command against a configured root. The required domain still includes missing dependencies, model failures, malformed dates, ambiguous sections, empty selections and storage failures. Allocation/encoding/filesystem failures are explicit operational outcomes, not successful results silently excluded from the review. UTF-8 success observations compare encodable text/bytes. No fairness, service termination, race isolation after validation or multi-store atomicity is assumed.

| Profile | Concrete representation and abstraction / observation | Constructor and invariant obligations |
| --- | --- | --- |
| store | File state is a finite map from paths to UTF-8 bytes. Abstract content is those same bytes. Submitted body and generated timestamp/separation framing are distinct observations. Source-span mutation observes literal prefix/body/suffix bytes. | `ensure_storage` establishes a usable root; append allocates only a fresh generated heading. `DiaryDocument.parse` retains the original text and ordered source ranges. Existing external files need not have canonical names or unique headings. Successful mutations preserve all outside bytes. |
| identity | `DiarySection.section_id` derives filename and heading. Lookup abstracts to missing / one source occurrence / ambiguous, rather than a globally unique record ID. A Unicode source offset is interpreted by the UTF-8 encoding of the corresponding source substring. | Arbitrary repeated delimiters are admissible. `unique_section` must establish one target before section mutation; no constructor may silently repair external content. File/heading renames produce new identities. |
| calendar | Supported Gregorian `date` values, years 1 through 9999. `dated_diary_files` observes dates as paths, `entry_options` as picker records and `adjacent_entry` as an optional neighbor. | Parse/filter valid dates before comparing; equality is date equality. Invalid/non-date filenames remain available to history scans. Rendering must still produce the required four-digit year across the required domain. |
| editor | State relation: `busy` means work pending; `original_draft is not None` means reviewing, with the original as abstract draft and current buffer as displayed proposal; otherwise current buffer is the editable draft. Submit closes the workflow. | Initial `EditorState` is editable, no proposal, not busy. Work/review block editing, submission and overlap. | selection | `None` is cancellation; every list, including `[]`, is an accepted payload. Persisted association equality is set equality over backend leaf identities. Path strings and leaf names are different observations. | Dialog constructors must preserve cancellation versus accepted-empty. Successful case analysis retains prior tags or applies intended tags. | tasks | `PendingTask` carries source path, line, parsed text/metadata and full raw source snapshot. Task key is a location, not durable identity. | key-equivalence | Equality of `normalize_todo_text` results is the exact normalized-key relation. | outcomes | Observe status/exception, stdout/stderr, Markdown bytes, backend associations, durable intent and completion receipt state together. | Complete, failed with no confirmed change, partial and uncertain are different abstract outcomes. Constructor/operation setup must record required intent before mutation. No journal/receipt implementation currently establishes this invariant. |
| config/backend/model/search | Config is effective root/model/backend origin; HTFS owns its hierarchy and SQLite/RDF; model response/failure is environmental; retrieval observes a finite ordered result list plus scope restriction. | Preflight establishes usable backend before workflows. Model configuration, invocation, availability and consent are separate. Search ties have no promised order; startup metadata initialization is permitted and does not authorize search-body mutation. |

The service constructor establishes its in-memory root/model representation, but not storage readiness by itself; operational CLI startup supplies required preflight. Config/metadata errors must remain explicit. Static helpers may be partial internally, while the public command has an independently specified failure outcome. This mapping does not strengthen caller preconditions merely to make a test pass.

For operation `C`, the obligation is: a concrete initial state related to an admissible abstract state, and a permitted input, must lead only to allowed observed outcomes; successful resulting states remain related. Termination/progress and concurrent histories would require separate evidence. A reference-model theorem is not evidence for this concrete relation.

## Design choices and unsettled interpretation

- **J01 — justified representation choice:** existing source spans, source snapshots and optional accepted lists can represent the approved contract without a UUID migration or new algebraic class hierarchy.
- **J02 — implementation design pending:** D-08's intent/receipt schema and recovery command spelling need design during repair. The product policy is already resolved. Missing representation/API is a conformance gap, not a reason to exclude those inputs or seek approval for the audit.
- **U03:** when one captured body contains manually entered reserved timestamp headings, it creates multiple new sections. The contract does not explicitly identify which should receive the single post-capture tag prompt; current code selects the latest parsed section. Foreign HTFS paths sharing a diary basename are also not separately checked here. These cases are not silently classified as correct.
- **U04:** similarity transport failure returns no match, while missing client/malformed response can raise. The boundary of “similarity-model call failure” for malformed responses needs clarification before changing policy. This is not evidence that TODO-06 is contradictory.

Other unchecked behavior is listed in mapping.json and the review. None blocks the independent mappings or confirmed findings above.
